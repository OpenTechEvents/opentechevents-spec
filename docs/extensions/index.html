Suggested extensions

Fields that are not in the core — yet

The schemas do not forbid extra fields, on purpose: you can use any of these today and your document stays valid. Each one has a recommended shape so that early adopters converge instead of each inventing their own, and an adoption count measured from the registered adopter feeds.

The counts are written by a script that reads the real feeds, never by hand. A field graduates into the core through a normal proposal, once its graduation question has an answer — and using it is what produces that answer.
